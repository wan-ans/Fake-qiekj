# Fake qiekj

Fake qiekj 是一个非官方的胖乖生活设备控制 Android 客户端，仅用于学习交流 Android 客户端界面与网络请求的实现方式。本项目禁止商业用途，请勿用于任何违法或损害他人利益的用途，使用产生的风险由使用者自行承担。

> 本项目与胖乖生活官方无关，请自行承担账号、设备、接口变更和平台规则风险。请不要把登录凭证、抓包文件或签名密钥上传到公开仓库。
> 本项目不内置任何设备、账号或历史数据；设备信息均来自使用者登录后的服务器账户。

## 使用步骤

### 1. 登录

1. 打开 App，进入底部导航的“我的”。
2. 输入手机号。
3. 点击“发送验证码”。
4. 输入短信验证码。
5. 点击“确认登录”。
6. 登录成功后可点击“查看当前 Token”确认本地 Token。
7. 登录之后可以通过扫码功能或者复制登录状态切换设备，请勿随意传播。
8. 如果登录泄露，可以退出账号重新登录，之前的token便会失效。

### 2. 启动设备

1. 进入“设备控制”。
2. 等待历史设备加载。
3. 点击目标设备。
4. 等待设备使用结束。
5. 软件会在设备结束后弹出订单详情，并保存到历史订单。
6. 软件对自动支付做了很多层兼容，但是还是会有自动支付触发不了的情况，软件会唤起支付宝胖乖生活小程序用于手动付款兜底。。。。。

### 3. 查看历史订单

1. 进入“我的”。
2. 点击“历史订单”。
3. 在弹出的二级界面查看最近订单。
4. 点击某条订单可再次查看订单详情。

### 4. 扫码/设备号添加设备

1. 进入“设备控制”，点右上角“扫码”扫设备二维码，或点“设备号”直接输入设备 SN。
2. 长按设备可备注名字、复制设备号、添加桌面快捷方式或删除记录。
3. 设备行右侧可直接“启动/关闭”。

### 5. 运行日志

1. 进入“我的”，在“深色模式”下方找到“运行日志”。
2. 点“开始记录”复现问题，再点“停止记录”。
3. 点“导出日志”保存为 txt，便于排查。


## 注意事项

- Token 会随手机号重新登录变化，这是平台正常行为；App 会保存最新登录得到的 Token，也可用“登录二维码/导入登录”在设备间迁移登录态。
- 接口返回结构变化时，可能需要同步更新 `Models.kt`、`DeviceApi.kt` 或 `SkuResultJsonAdapterFactory.kt`。
